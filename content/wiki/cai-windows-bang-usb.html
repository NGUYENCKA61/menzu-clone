Cài lại Windows là cách sạch nhất để bắt đầu với tool: hết xung đột phần mềm, hết dấu vết tool cũ, và các bước chuẩn bị máy làm một lần là xong. Bài này hướng dẫn tự cài Windows 10 hoặc 11 tại nhà bằng USB, mất khoảng 30 đến 45 phút. Đọc hết một lượt trước khi làm.

Chuẩn bị

  • USB trống dung lượng từ 8 GB. Mọi dữ liệu trong USB sẽ bị xoá.
  • Một máy đang chạy Windows để tạo USB cài (có thể là chính máy cần cài).
  • Sao lưu dữ liệu ở ổ C ra ổ khác hoặc lên mây: Desktop, Documents, Downloads, ảnh, file game lưu.
  • Ghi lại key Windows nếu bạn mua bản quyền riêng. Máy hãng có sẵn bản quyền trong BIOS, cài xong tự kích hoạt.
  • Biết phím vào Boot Menu của máy: thường là F12, F11, F8 hoặc Esc; vào BIOS là Delete hoặc F2.

Bước 1: tạo USB cài Windows

  1. Vào trang tải Windows của Microsoft, chọn Windows 11 (hoặc Windows 10) và tải Media Creation Tool. Chỉ tải từ microsoft.com, không dùng bản ghost hay bản "lite" vì tool cần Windows nguyên gốc.
  2. Chạy Media Creation Tool, chọn Create installation media, ngôn ngữ và phiên bản để mặc định, chọn USB flash drive, chọn đúng USB của bạn và chờ tải xong.
  3. Nếu máy không đạt yêu cầu Windows 11 (không có TPM 2.0), dùng Rufus: chọn file ISO Windows 11, ở hộp thoại tuỳ chọn tích "Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0", partition scheme chọn GPT, target system UEFI.

Bước 2: khởi động từ USB

  1. Cắm USB, khởi động lại máy, bấm liên tục phím Boot Menu khi vừa hiện logo hãng.
  2. Chọn dòng có chữ UEFI và tên USB. Không chọn dòng Legacy, vì tool yêu cầu máy chạy ở chế độ UEFI.
  3. Nếu không thấy USB, vào BIOS tắt Secure Boot tạm thời và bật chế độ UEFI, xem Tắt Secure Boot và bật ảo hoá.

Bước 3: cài đặt

  1. Chọn ngôn ngữ, bấm Install now. Hỏi key thì chọn I don't have a product key, máy sẽ tự kích hoạt sau nếu từng có bản quyền.
  2. Chọn phiên bản (Home hoặc Pro, trùng với bản cũ để giữ bản quyền), đồng ý điều khoản.
  3. Chọn Custom: Install Windows only.
  4. Ở danh sách phân vùng, chọn lần lượt các phân vùng của ổ cài Windows cũ (ổ C, phân vùng System, Reserved, Recovery của cùng ổ đó) và bấm Delete cho tới khi còn một vùng Unallocated. Không đụng ổ D, E chứa dữ liệu.
  5. Chọn vùng Unallocated, bấm Next. Máy tự chia phân vùng, chép file và khởi động lại vài lần. Khi máy khởi động lại, rút USB ra hoặc đừng bấm phím gì để máy vào ổ cứng.
  6. Thiết lập ban đầu: khu vực, bàn phím, mạng, tài khoản. Windows 11 Home đòi tài khoản Microsoft; muốn tài khoản cục bộ thì rút mạng ở bước này rồi làm theo gợi ý trên màn hình.

Bước 4: sau khi cài xong

  1. Cài driver: vào trang hãng mainboard hoặc laptop tải driver chipset, mạng, âm thanh; driver card đồ hoạ tải từ NVIDIA hoặc AMD.
  2. Chạy Windows Update một lượt rồi khởi động lại.
  3. Cài runtime cần cho tool: Visual C++ Redistributable, .NET Desktop Runtime, DirectX, xem Cài runtime cần thiết.
  4. Làm các bước chuẩn bị máy: tắt Windows Defender, Core Isolation, Secure Boot và các anti-cheat khác theo Setup máy chuẩn.
  5. Không cài phần mềm diệt virus bên thứ ba. Chúng xoá file tool và bắt bạn cài lại từ đầu.
  6. Cài game và nền tảng (Steam) trước, tool sau.
Cài lại Windows không gỡ khoá máy (HWID ban). Nếu máy đã bị khoá, bạn vẫn cần spoofer. Nhiều spoofer trên shop ghi "không cần cài Win" vì đã có cleaner.

Gặp lỗi thì sao

  • "Windows cannot be installed to this disk. The selected disk is of the GPT partition style": USB đang boot kiểu Legacy. Khởi động lại và chọn dòng UEFI của USB.
  • Không tìm thấy ổ cứng lúc cài: máy dùng Intel RST/VMD. Tải driver IRST từ trang hãng, giải nén vào USB, bấm Load driver ở màn hình chọn ổ.
  • BitLocker đòi key khôi phục: lấy key ở account.microsoft.com/devices/recoverykey trên điện thoại.
