Hai thiết lập trong BIOS mà gần như tool nào cũng đụng tới. Secure Boot chỉ cho Windows nạp driver có chữ ký Microsoft, mà tool dùng driver riêng nên phải tắt. Ảo hoá thì ngược lại: tool cần ảo hoá phần cứng (Intel VT-x, AMD SVM) bật trong BIOS, nhưng các tính năng ảo hoá của Windows (Core Isolation, Hyper-V) phải tắt, vì chúng chiếm quyền ở tầng mà tool cần.

Phần 1: tắt Secure Boot

  1. Nếu ổ C bật BitLocker, tạm ngưng trước: Start, gõ Manage BitLocker, chọn Suspend protection. Không làm bước này, Windows sẽ hỏi key khôi phục sau khi đổi BIOS.
  2. Khởi động lại máy, bấm liên tục phím vào BIOS khi vừa lên logo hãng: Delete hoặc F2 với máy bàn; F2, F10 hoặc Esc với laptop.
  3. Tìm mục Boot hoặc Security: ASUS: Boot, Secure Boot; MSI: Settings, Advanced, Windows OS Configuration; Gigabyte: BIOS, Secure Boot; ASRock: Security, Secure Boot. Laptop thường nằm trong Security hoặc Boot.
  4. Đặt Secure Boot = Disabled. Có máy bắt đổi OS Type sang Other OS, hoặc chọn Clear Secure Boot keys trước thì mới tắt được.
  5. Bấm F10 để lưu và khởi động lại.

Kiểm tra: Start, gõ msinfo32, dòng Secure Boot State ghi Off. Windows 11 vẫn chạy bình thường khi Secure Boot tắt, chỉ các bản cập nhật lớn mới nhắc.

Phần 2: bật ảo hoá trong BIOS

  1. Vào lại BIOS như trên.
  2. Tìm mục CPU Configuration hoặc Advanced: với Intel là Intel Virtualization Technology (VT-x), với AMD là SVM Mode. Đặt Enabled.
  3. Tuỳ tool, mục VT-d (Intel) hoặc IOMMU (AMD) để Disabled trừ khi tài liệu ghi khác.
  4. F10 lưu, khởi động lại.

Kiểm tra: mở Task Manager, thẻ Performance, mục CPU, dòng Virtualization: Enabled.

Phần 3: tắt ảo hoá của Windows

  1. Core Isolation: Windows Security, Device security, Core isolation details, tắt Memory integrity, khởi động lại. Chi tiết: Tắt Core Isolation.
  2. Hyper-V và các nền tảng ảo: Start, gõ Turn Windows features on or off, bỏ tích Hyper-V, Virtual Machine Platform, Windows Hypervisor Platform, Windows Sandbox, Windows Subsystem for Linux. Bấm OK và khởi động lại.
  3. Vẫn còn vướng, mở Command Prompt bằng quyền admin và chạy: bcdedit /set hypervisorlaunchtype off, rồi khởi động lại. Muốn bật lại sau này: bcdedit /set hypervisorlaunchtype auto.

Kiểm tra: trong msinfo32, dòng Virtualization-based security ghi Not enabled, và dòng A hypervisor has been detected không xuất hiện.

Tóm lại: BIOS bật ảo hoá, Windows tắt ảo hoá. Làm ngược lại là tool báo lỗi driver hoặc không inject được.

Câu hỏi hay gặp

  • Tắt Secure Boot có mất bản quyền Windows không? Không. Bản quyền gắn với tài khoản hoặc mainboard, không gắn với Secure Boot.
  • Chơi game khác có Vanguard (Valorant) thì sao? Vanguard đòi Secure Boot và TPM bật trên Windows 11. Khi chơi Valorant bằng tool của shop, làm theo tài liệu riêng của tool đó; khi không dùng tool, bật lại Secure Boot rồi khởi động lại.
  • Không thấy mục ảo hoá trong BIOS: cập nhật BIOS từ trang hãng, hoặc mục đó nằm trong Advanced Mode (bấm F7 trên ASUS).
  • Máy khởi động vào màn hình xanh sau khi đổi: vào BIOS đặt lại như cũ, kiểm tra chế độ SATA (AHCI) không bị đổi theo.

Các bước còn lại để máy sẵn sàng (Defender, TPM, runtime, anti-cheat khác) ở bài Setup máy chuẩn THÍCH THÌ HACK. Riêng Valorant, Vanguard đòi Secure Boot bật, nên mỗi bản trong danh mục Hack Valorant có tài liệu riêng cho bước này.
