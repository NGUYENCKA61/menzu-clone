Config là file lưu toàn bộ thiết lập của menu tool: aimbot bật hay tắt, FOV bao nhiêu, smooth bao nhiêu, ESP vẽ kiểu gì, phím tắt nào. Thay vì chỉnh lại từng ô mỗi lần mở game, bạn lưu một lần rồi nạp lại. Shop tặng kèm config ở một số bản (trang sản phẩm ghi "tặng kèm config"), và cộng đồng cũng chia sẻ config cho nhau.

Setting, save config, load config

  • Setting: các ô chỉnh trong menu. Chỉnh xong mà không lưu thì lần mở sau về mặc định.
  • Save config: lưu thiết lập hiện tại thành một file, thường có tên do bạn đặt. Nhiều tool cho lưu nhiều config: một cho chơi thường, một cho leo rank, một cho chế độ zombie.
  • Load config: nạp lại file đã lưu. Sau khi load, kiểm tra lại độ phân giải và độ nhạy chuột vì config phụ thuộc hai thứ đó.
  • Preset / Default: thiết lập mặc định của tool. Lỡ chỉnh hỏng thì load default rồi chỉnh lại.

File config nằm ở đâu

Tuỳ tool: cùng thư mục với loader, trong thư mục %APPDATA% hoặc %LOCALAPPDATA%, hoặc lưu trên máy chủ của tool theo key. Tài liệu của từng tool trong Tài liệu ghi đường dẫn cụ thể. Trước khi cập nhật tool hoặc cài lại Windows, chép file config ra chỗ khác.

Legit config và rage config

  • Legit: aimbot FOV nhỏ (2 đến 5), smooth cao (10 trở lên), chỉ nhắm ngực, ESP chỉ box hoặc radar, không silent aim. Nhìn như người chơi giỏi, ít bị báo cáo, hợp với acc có giá trị.
  • Rage: FOV lớn, smooth 0, nhắm đầu, silent aim, no spread. Thắng nhanh, bị báo cáo nhanh, chỉ dành cho acc phụ và chế độ không rank.
  • Semi-rage: ở giữa: aimbot rõ hơn legit nhưng tắt các chức năng lộ nhất.
Config shop tặng kèm thường là legit, đã cân cho đa số máy. Dùng nó trước, chơi vài trận rồi mới chỉnh dần theo tay mình.

Tự chỉnh config từ đầu

  1. Tắt hết, bật ESP box trước để quen cách tool vẽ.
  2. Bật aimbot với FOV 3, smooth 15, hitbox ngực. Chơi hai ba trận.
  3. Giảm smooth từng nấc nhỏ tới khi thấy đủ dùng mà vẫn tự nhiên. Không hạ về 0.
  4. Thêm recoil control ở mức 50 đến 70%, không để 100%.
  5. Save lại với tên có ngày, ví dụ "legit-cs2-14-10", để lỡ chỉnh hỏng còn quay lại.

Những lỗi quen thuộc

  • Load config xong tâm kéo loạn: config làm cho độ nhạy chuột khác. Đặt độ nhạy trong game về đúng số ghi kèm config, hoặc chỉnh lại smooth.
  • ESP vẽ lệch người: độ phân giải hoặc chế độ màn hình khác lúc tạo config. Chạy game ở cửa sổ không viền đúng độ phân giải màn hình.
  • Mất config sau khi tool cập nhật: bản mới đổi định dạng file. Lấy config mới từ tài liệu của tool hoặc chỉnh lại theo các bước trên.
  • Config tải trên mạng: chỉ nạp file config dạng văn bản của đúng tool đó. Không chạy file .exe ai đó gửi và gọi là "config".

Các từ trong menu như FOV, smooth, hitbox, silent aim được giải nghĩa ở trang Thuật ngữ.
