Hơn một nửa yêu cầu bảo hành shop nhận được là máy chưa chuẩn bị đúng: Defender xoá file, Secure Boot còn bật, thiếu runtime. Đây là danh sách chuẩn của THÍCH THÌ HACK, làm một lần cho mọi tool trong danh mục tool. Mỗi mục có trang hướng dẫn riêng kèm cách kiểm tra, trong mục Tài liệu.

Yêu cầu máy

  • Hệ điều hành: Windows 10 hoặc Windows 11 nguyên gốc, cập nhật mới. Không dùng bản ghost, bản lite, không dùng Windows 7.
  • BIOS: chế độ UEFI, Secure Boot tắt, ảo hoá (Intel VT-x hoặc AMD SVM) bật.
  • CPU: Intel hoặc AMD có tập lệnh AVX (hầu hết Core i3/i5/i7 và Ryzen từ 2012 trở lại đây; Pentium và Celeron đời cũ thường không có).
  • Mạng: mạng nhà, ổn định. Hạn chế 4G phát wifi và mạng quán, hay rớt kết nối tới máy chủ tool.
  • Màn hình: game chạy ở chế độ cửa sổ không viền (Borderless / Windowed Fullscreen) để overlay của tool hiện được.
  • Nền tảng: game bản Steam với các tool ghi "Nền tảng: Steam". Bản của launcher khác có thể không tương thích.

Danh sách chuẩn bị, làm theo thứ tự

  1. Tắt Windows Defender (bảo vệ thời gian thực, bảo vệ đám mây, gửi mẫu) và gỡ phần mềm diệt virus khác. Thêm thư mục chứa tool vào Exclusions. Hướng dẫn: Tắt Windows Defender.
  2. Tắt Secure Boot trong BIOS. Hướng dẫn theo từng hãng mainboard: Tắt Secure Boot.
  3. Tắt Core Isolation (Memory integrity) trong Windows Security. Hướng dẫn: Tắt Core Isolation.
  4. Tắt TPM nếu tool yêu cầu (một số spoofer). Hướng dẫn: Tắt TPM.
  5. Bật ảo hoá trong BIOS, tắt ảo hoá của Windows (Hyper-V, Windows Sandbox, Virtual Machine Platform). Chi tiết ở bài Tắt Secure Boot và bật ảo hoá.
  6. Tắt các anti-cheat khác đang chạy nền (FACEIT, Vanguard khi chơi game khác, ESEA). Hướng dẫn: Tắt các anti-cheat khác.
  7. Cài runtime: Visual C++ Redistributable (2015 đến 2022, cả x64 và x86), .NET Desktop Runtime, DirectX. Hướng dẫn: Cài runtime cần thiết.
  8. Tắt overlay của Discord, GeForce Experience, MSI Afterburner, RivaTuner, Steam overlay nếu tài liệu tool yêu cầu. Chúng tranh nhau vẽ lên game và làm ESP không hiện.

Kiểm tra trước khi mở tool

  • Bấm Start, gõ msinfo32: BIOS Mode ghi UEFI, Secure Boot State ghi Off, Virtualization-based security ghi Not enabled.
  • Mở Task Manager, thẻ Performance, mục CPU: Virtualization: Enabled.
  • Windows Security không còn chấm đỏ về bảo vệ thời gian thực.
  • Game mở được ở chế độ cửa sổ không viền, đúng độ phân giải màn hình.
Cài lại Windows sạch rồi làm danh sách này một lần là cách nhanh nhất với máy đã cài nhiều thứ, xem Cài Windows bằng USB.

Thứ tự chạy tool mỗi lần chơi

  1. Khởi động máy, chưa mở game.
  2. Nếu dùng spoofer tạm thời: chạy spoofer trước.
  3. Mở loader bằng Run as administrator, nhập key, chờ loader báo sẵn sàng.
  4. Mở game theo đúng thứ tự tài liệu của tool ghi (trước hoặc sau khi inject).
  5. Vào trận, mở menu bằng phím ghi trong tài liệu, nạp config.

Khi gửi bảo hành, shop sẽ hỏi lại từng mục trong danh sách này và xin ảnh chụp, nên làm đủ trước sẽ được xử lý nhanh hơn nhiều. Chi tiết ở quy trình bảo hành.
